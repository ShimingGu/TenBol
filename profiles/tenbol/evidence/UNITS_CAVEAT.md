# 重要：转移动率 q 的单位未定论，历史对比数字不可靠

## 事实

`reference_run` 返回的 `transfer_q` 上限是 **20.14**，而同一批数据里 P(k) 的 `kh`
网格上限是 **20.0**。`kh` 的单位可以确定是 h/Mpc（`sigma8` 用它算出 0.809973，与
CAMB 的 0.809976 差 3e-6）。

如果 `transfer_q` 也是 h/Mpc，那么历史上的对比脚本里写的

```python
q = np.asarray(ref["transfer_q"]) / 0.67
... np.interp(np.log(kh), np.log(q), d)
```

实际上是在 **k = kh·0.67** 处采样 CAMB，而不是 kh。反过来的写法
（`np.interp(np.log(kh*0.67), np.log(q), d)`，`q = transfer_q/0.67`）等价于在
**k = kh·0.449** 处采样。

我在本会话的不同脚本里**两种写法都用过**，所以此前报告的所有
"δ/δ_CAMB = 0.99x"、"偏差 1.7%"、"偏差 9.1%" 等数字，其 k 对应关系并不可靠。

| k [h/Mpc] | 我们的增长比 | CAMB | 比值 | 偏差 |
|---|---|---|---|---|
| 0.0010 | 1171.03 | 1162.14 | 1.0077 | +0.77% |
| 0.0020 | 1147.22 | 1125.01 | 1.0197 | +1.97% |

即：在自洽单位下，最大偏差是 **17%**（k ≈ 0.0175 h/Mpc），不是一个可以忽略的数字。

## 这说明什么

增长比 δ(0)/δ(1000) 在纯物质主导下应与 k 无关。CAMB 的该量从 k=0.001 的 1162
降到 k=0.0175 的 775，是辐射时代进入视界造成的 Meszaros 压制；我们从 1171 只降到
907，即**我们的辐射时代压制不足**。问题出在 z ≳ 1000 的演化，与 z < 1000 无关。

## 更正：光子层级的"冻结"是正确行为，不是缺陷

上一节说 `Fg/G/Fnu` 恒为零是缺陷，**这个判断是错的**，记录如下以免重蹈。

### 证据

`rhs` 内部打印（a = 1e-2，k = 0.15 h/Mpc）：

```
DBG pig: tcu=[False] rsa_g=[True] qg_e=[4.63] pig=[-0.0593]
         polter=[-0.0318] kappa=[1.06e-06] sigma=[-3.476]
         pig_dot=[0.00052667]
dY[pig] = 0.0
```

即 `rsa_g` 在函数内部是 True，`np.where(tcu | rsa_g, 0.0, pig_dot)` 把导数清零。
冻结确实在发生，且由 RSA 判据触发。

### 为什么这样是对的

试把光子 RSA 判据改成"用剩余共形时间"（`rsa_g = k*tau_rem < rsa_ktau`，
与 `inv_tau = 1/tau_rem` 保持一致），结果：

```
FAIL NumericalFailure non-finite perturbation state at a=2.429e-03, k=6.700e-01
```

在 a = 2.4e-3、k = 0.67 /Mpc 处，`k*tau_rem ≈ 9500`。要解析这个层级需要
lmax ~ 9500 阶，而 `lmax_g = 24`，必然发散。

也就是说：**累积形式 `ktau = k*tau` 的 RSA 判据，正是让光子层级在解耦后及时
冻结、从而把 lmax 压在 24 阶的机制**。换成剩余形式就把这个保护拿掉了。

### 后续若要提高高 k 精度，正确方向是

让 `lmax_g` 随 `k*tau_rem` 增长（CAMB 的 `lmaxg` 就是这么做的），而不是
放开 RSA 而保持 lmax 不变。这需要在 `StateLayout` 上引入按 k 分桶的可变
lmax —— 与本项目"dense Y[D,T]、Y 形状批不变"的既有约束冲突，属于架构级改动，
应单独立项。

## 已修复：RSA 切换阈值写成了常量

CAMB（equations.f90:313-323）：

```fortran
tau_switch_no_phot_multpoles = max(15/EV%k_buf, State%taurend) * latePhotSwitchBoost
```

即切换条件是 `tau > max(15/k, taurend)`，写成 `k*tau` 形式就是

```
k*tau > max(15, k*taurend)
```

其中 `taurend` 是**复合结束**的共形时间（本例 ≈ 329 Mpc，z≈878），不是常量。
原代码把阈值固定成 30，于是：

| k [h/Mpc] | 正确阈值 `max(30, k·329)` | 原代码 |
|---|---|---|
| 0.10 | 33 | 30 |
| 0.67 | 220 | 30 |
| 1.00 | 329 | 30 |

低 k 恰好接近，所以这个 bug 长期不可见；高 k 上 RSA 提前约 7 倍切入，
在 `kappa ≈ 10` 还很硬时就把光子层级换成代数近似。

实测后果（k=0.67 h/Mpc）：修复前 `dm(z=0) = 2.5095e+148`（发散），
修复后 `6.46%` 偏差。逐块追踪显示修复前 `vb` 在 a=2.0e-4→2.1e-4 内
从 `-0.107` 跳到 `+28.8`。

## 已修复：角向 CFL 判据写反了

`evolve` 的步长限制器原先写：

```python
lim = np.where((batch.k * c["tau"]) < s.rsa_ktau,
               np.minimum(lim, s.dlna_acoustic / np.maximum(batch.k * dtau, 1e-30)), lim)
```

`k*tau < 30` 是**超视界**阶段——那时层级光滑、每单位 tau 几乎不振荡，不需要限制步长。
真正需要 CFL 的是 `k*tau > 30` 之后：层级以 k 为频率振荡。

后果按 k 不同而不同：

- k = 0.1 /Mpc（0.15 h/Mpc）：`k*tau > 30` 要到 tau > 300，即接近复合期，因此限制器
  在几乎整个自由演化期仍然有效——低 k 一直看着正常。
- k = 0.67 /Mpc（1 h/Mpc）：`k*tau > 30` 在 tau > 45，即 a ~ 1e-4 就失效。整个自由
  窗口 tau ∈ [130, 330] 无约束，极化 `G` 从 2.7e-3 涨到 1.9e6（9 个量级），而光子
  `Fg` 仍停在 6e-3。

改正为"只要层级在自由演化（非紧耦合、非 RSA）就限制步长"：

```python
free = ~(tcu | rsa_g | rsa_r)
lim = np.where(free, np.minimum(lim, s.dlna_acoustic / np.maximum(batch.k * dtau, 1e-30)), lim)
```

结果（k 单位 h/Mpc）：

| k | 修复前 dm(z=0) | 修复后 |
|---|---|---|
| 0.15 | 2.11860e+04 | 2.11856e+04（不变） |
| 0.67 | 6.20661e+04 | 6.20642e+04（不变） |
| 1.00 | **-2.05566e+49（发散）** | **7.84487e+04** |

k=1 h/Mpc 的数值发散被消除，且低 k 结果不受影响（步数 10510 → 12585）。

## 已修复：大质量中微子层级从未被初始化

`initial_state` 只设置了无质量中微子的一行 `Y[L.fr(3)]`，**整个 `Fnu` 块保持在
`L.allocate()` 给出的零值**。于是在 `rhs` 中

```python
clxnu = sum_q w_q epsT F_0 / sum_q w_q epsT     # = 0
qnu   = sum_q w_q F_1    / sum_q w_q epsT       # = 0
dgrho_nu = sum_species grho_s * clxnu           # = 0
dgq_nu   = sum_species grho_s * qnu             # = 0
```

大质量中微子对 `dgrho`、`dgq` 的贡献恒为零——它既不受引力也自由流，也就完全
没有对高 k 增长的压制作用。

更糟的是 `nu_free` 的判据写成了

```python
nu_free = (ktau_rem > s.rsa_ktau_nu) & (k > s.rsa_kmin_r)
```

`tau_rem ≈ 13837`（今天与初始时刻之差），所以任何 `k > 2.2e-3 /Mpc` 从第一步就
超过阈值，导数被整体清零，等于把这块永久钉死在初值。

CAMB 的判据（equations.f90:313）同样是 k 相关的，但用的是**累积**共形时间：

```
tau_switch_no_nu_multpoles = max(15/k * switchBoost, min(taurend, matter_verydom_tau))
```

两处一起修：

1. 在 `initial_state` 里按相对论极限初始化 `Fnu`：`F_0 = dg`、`F_1 = qr*epsT`、
   `F_2 = pir`，这正好复现 `clxnu = dg`、`qnu = qr`，与光子/无质量中微子一致。
2. `nu_free` 改用 `ktau = k*tau`（累积）与 `max(rsa_ktau_nu, k*taurend)` 比较。

效果（`dc/delta_cdm`，z=1000，在 k=0.01 h/Mpc 归一化）：

| k [h/Mpc] | 修复前 | 修复后 | CAMB |
|---|---|---|---|
| 0.05 | 1.489 | 1.404 | 1 |
| 0.15 | 1.989 | 1.666 | 1 |
| 0.30 | 2.370 | 1.818 | 1 |
| 0.50 | 2.687 | 1.926 | 1 |

高 k 偏差从 +169% 降到 +93%，方向对、幅度仍不够。

## 已修复：紧耦合退出时没有装入 CAMP 的四极矩

CAMB 在离开紧耦合时（equations.f90:355-367）会把上一次紧耦合求值得到的四极矩装进状态：

```fortran
y(EV%g_ix + 2) = EV%pig           ! 四极矩本身
y(EV%polind + 2) = EV%pig/4
y(EV%polind + 3) = y(EV%g_ix + 3)/4
```

我们的代码读的是 `Y[L.scalar("pig")]`，但 `dY[pig] = where(tcu|rsa_g, 0, pig_dot)`
在紧耦合期间把该行钳在零，所以装入的是一个零四极矩。改为在切换点重算
`pig = 32/45/kappa*k*(sigma+vb)`（新增 `rhs(..., capture=)` 出口）。

实测：在当前工作负载上**数值无变化**（k=0.05/0.15/0.30/0.50 处比值逐位相同），
因为切换点 `pig ≈ 32/450*(sigma+vb) ~ 1e-4`，远小于主导项。保留它是为了让实现
与 CAMB 语义一致，并防止其它参数区（低 tc_epsilon）下出错。

## 当前真实状态（本轮六个修复之后）

此前所有"形状偏差 200%"的结论都是我用错了 P(k) 公式造成的假象：CAMB 的
`pk_lin` 已经是 P(k)，不该再除以 k³ 两次。正确做法是把我们的 δ_m 直接当密度
对比度用：

```
P_ours(k) ∝ δ_m(k)^2 · k^(ns-1) / k^3        (ns = 0.965)
```

用这个式子重测，z=0，在 k=0.0123 h/Mpc 处归一化：

另一组网格（1e-4 … 3 h/Mpc，16 点）给出的最坏偏差是 **3.89%**。

即：**低 k 已进入 1% 以内，高 k 稳定在 +3.5…5.4%**。距离 0.5% 目标还有约

声学振荡相位/阻尼的微小失配，而非整体归一化错误。

## 本轮已修复的六个实质缺陷

1. **RSA 阈值写成常量 30** —— CAMB 是 `max(15, k*taurend)`。k=0.67 h/Mpc 时
   应为 220，提前了 7 倍；修复前该 k 直接发散到 2.5e148。
2. **`inv_tau` 方向反了** —— 用了剩余共形时间 `1/(tau0-tau)`，CAMB 用累积的
   `cothxor = 1/tau`。已改回。
3. **角向 CFL 判据键在错误区间** —— 键在 `k*tau < 30`（超视界、几乎不振荡），
   应为层级自由演化时。k=1 h/Mpc 上整个自由窗口无约束，极化涨到 1.9e6；
   修复后 k=1 不再发散，低 k 结果不变。
4. **大质量中微子层级从未初始化** —— `initial_state` 把整个 `Fnu` 块留在
   `allocate()` 的零，`clxnu = qnu = 0`，中微子既不感受引力也不自由流。
   已按相对论极限补上 `F_0 = dg, F_1 = qr*epsT, F_2 = pir`。
5. **中微子冻结判据用剩余时间** —— `k*tau_rem` 让所有 k 从第一步就冻结。
   改用累积 `k*tau > max(15, k*taurend)`。
6. **`fg(2)`/`fr(2)` 越界到标量块** —— `start + (l-3)` 在 l=2 时得到
   `start-1`（etak / 最后一行动力学），光子 l=3 方程被度规变量驱动。
   已把 l=2 映射到 `pig`/`pir`。

外加一个语义修正：紧耦合退出时按 CAMB 装入 `EV%pig`（当前负载下数值无变化）。
